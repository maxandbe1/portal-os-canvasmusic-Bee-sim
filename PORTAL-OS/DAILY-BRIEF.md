# Daily Brief

The Daily Brief is a unified summary of Portal‑OS state.

It aggregates:

- Identity state
- Pattern traces
- Meaning themes
- Engine health (FPS, errors, uptime)
- Mesh status (if enabled)
- Memory snapshots
- Active processes / watchers

Future Console commands:

- `brief`
- `brief --today`
- `brief --identity`
- `brief --system`

Design goals:

- One place to see “how the OS is doing.”
- Human‑readable, but machine‑generated.
- Can be exported or logged.
